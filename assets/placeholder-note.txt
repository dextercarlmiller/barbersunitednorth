BARBERS UNITED NORTH — PHOTO PLACEHOLDERS
==========================================

This folder is reserved for barber headshot photos when they become available.

To add a barber's photo:
1. Place the image file here (e.g. dhugga.jpg, bear.jpg, etc.)
2. In index.html, find the barber's card avatar div
3. Remove the <span> initials element
4. Add: <img src="assets/[filename]" alt="[Barber Name]" />

Each card's avatar div already has overflow:hidden and object-fit:cover
applied via team.css so photos will automatically be cropped to a circle.
